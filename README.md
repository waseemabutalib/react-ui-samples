# React UI Samples

Small React and TypeScript UI samples for case studies, filters, cards, and accessible interface patterns.

This repository is a public-safe code sample built from scratch with fake/sanitized data. It is not copied from private client work, UH materials, Anarchy scripts, or any production project folder.

## What It Demonstrates

- React components with TypeScript props and data types.
- Filterable project/case study cards.
- Reusable skill tags and status labels.
- Responsive layout with plain CSS.
- Accessible buttons, semantic sections, visible focus states, and screen-reader-friendly labels.
- Clean project structure suitable for a small frontend sample.

## Tech Stack

- React
- TypeScript
- Vite
- CSS

## Project Structure

```text
src/
  components/
    FilterTabs.tsx
    ProjectCard.tsx
    SkillTag.tsx
  data/
    projects.ts
  App.tsx
  main.tsx
  styles.css
  types.ts
```

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
