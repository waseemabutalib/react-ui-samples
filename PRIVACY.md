# Public Sharing And Privacy Notes

This repository is built from scratch as a public code sample.

## Safe To Include

- Fake or sanitized project data.
- Recreated UI components.
- Generic portfolio/card/filter patterns.
- Accessibility and responsive design notes.
- Code written specifically for public display.

## Not Included

- Raw client code.
- UH internal materials.
- Private archive data.
- Anarchy raw scripts.
- Production portfolio source copied from old folders.
- Credentials, API keys, or deployment secrets.
- Contact form submissions or private messages.

## Sharing Approach

The goal is to show React, TypeScript, component structure, and frontend UI thinking without exposing private project materials.
